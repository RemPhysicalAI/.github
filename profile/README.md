# REM PhysicalAI

**Robots that dream themselves better.**

A small learning system that lives inside a robot. It learns by
itself, dreams in simulation while it sleeps, and wakes up better.
No cloud. No connection. The intelligence stays in the body.

**Built for the Arduino Ventuno Q** — Arduino's Qualcomm-powered
board for physical AI, not yet on sale. When it ships, we ship.

→ **The system:** [rem-physical-ai](https://github.com/RemPhysicalAI/rem-physical-ai)
